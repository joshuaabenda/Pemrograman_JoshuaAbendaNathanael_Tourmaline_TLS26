# Pemrograman_JoshuaAbendaNathanael_Tourmaline_TLS26
Repositori ini berisi penyelesaian Tugas Pemrograman TLS 2026 untuk Fase 1 (Perancangan Logika) dan Fase 2 (Implementasi Kode Program).

Isi Repositori:
1. Laporan_Fase_1.pdf
Dokumen laporan yang berisi pseudocode, flowchart, dan penjelasan logika untuk Problem 1 dan Problem 2.
2. problem1.cpp
Program C++ untuk Problem 1 (The Last Astronaut), yaitu simulasi eliminasi astronot melingkar dengan perubahan nilai hitungan K secara dinamis.
3. problem2.cpp
Program C++ untuk Problem 2 (Alien-In-The-Middle), yaitu enkripsi pesan teks menggunakan metode pergeseran karakter berantai.
